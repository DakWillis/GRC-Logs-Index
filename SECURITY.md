# Security policy

## Scope

This repository contains documentation and templates only. There is no executable application, no dependency chain, and no data processing.

## Reporting a concern

Two categories of report are welcome.

**Sanitization concerns.** If anything in this repository appears to identify a real organization, individual, system, or vendor, open an issue without restating the identifying detail, or contact the maintainer directly. Sanitization failures are treated as the highest-priority issue class in this repository and are corrected immediately.

**Framework accuracy.** If a control mapping is wrong or reflects a superseded framework version, open an issue citing the control and the version. Corrections are welcome and credited.

## What does not belong in this repository

Contributors and the maintainer must not commit:

- Real organization, staff, or vendor names
- Asset identifiers, serial numbers, hostnames, IP addresses, or internal URLs
- Screenshots containing any of the above
- Live credentials, tokens, or keys of any kind
- Contract terms, pricing, or commercial detail
- Audit findings attributable to an identifiable organization

## Practicing what the archive documents

This repository is public, so its own control set is worth stating: pre-commit review for sanitization on every entry, no screenshots without redaction review, and disposition of any entry that cannot be sanitized without losing meaning. An archive about evidence discipline is an odd place to be careless with evidence.
